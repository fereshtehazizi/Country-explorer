## API Endpoints Used

| Endpoint | Method | Description |
|----------|--------|-------------|
| `https://restcountries.com/v3.1/all` | GET | Fetches a list of all countries |
| `https://restcountries.com/v3.1/name/{name}` | GET | Searches for a specific country by name |
